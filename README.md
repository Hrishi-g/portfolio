# 🚀 Minimalist Astro Developer Portfolio

A ultra-fast, modern, monochrome developer portfolio website built with **Astro 4**, **Tailwind CSS**, and **TypeScript**.

---

## ⚡ Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Local Development Server
```bash
npm run dev
```
Open [http://localhost:4321](http://localhost:4321) in your browser.

### 3. Build for Production
```bash
npm run build
```

---

## 📝 Updating Your Portfolio Content

All your portfolio data (bio, status, social links, projects, skills, work experience, and education) is stored cleanly in a single TypeScript file:

📍 **`src/data/portfolioData.ts`**

Simply open `src/data/portfolioData.ts` to update your details!
